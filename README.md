-- -- -- -- -- Monthly Financial Budget Savings Tracker -- -- -- -- --

The Monthly Financial Budget Savings Tracker is a Java-based console application designed to help users manage their personal finances by tracking monthly income, expenses, and savings goals.
This project demonstrates the practical application of Data Structures and Algorithms (DSA) concepts such as Linked Lists, Stacks, Queues, HashMap, Priority Queue, Searching, and Sorting algorithms. The program allows users to add expenses, analyze financial data, and generate monthly summaries.
The system efficiently stores and processes expense records while providing features such as expense searching, sorting, history tracking, and payment processing.

Features - 
• Set monthly income
• Set savings goal
• Add expense with category and payment method
• View all expenses for a month
• Generate monthly financial summary
• Search expenses by category
• Sort expenses by amount using Bubble Sort
• View recent expense history using Stack
• Process payments using Queue
• Find highest expense using Priority Queue

Data Structures Used - 
This project uses several important Data Structures:
Linked List
Used to store expense records dynamically for each month.

Stack
Used to maintain recent expense history using the LIFO principle.

Queue
Used to process payment transactions in FIFO order.

HashMap
Stores financial data for different months for fast retrieval.

Priority Queue
Used to quickly identify the highest expense recorded.

Searching
Linear search is used to find expenses by category.

Sorting
Bubble Sort algorithm is used to sort expenses by amount.
